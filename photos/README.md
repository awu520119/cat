# 俏咪素材

把想用于桌宠轮播的图片或视频放到这个目录，然后重新运行：

```bash
./scripts/build.sh
```

支持图片格式：`jpg`、`jpeg`、`png`、`webp`、`heic`、`tiff`。
支持视频格式：`mp4`、`m4v`、`mov`，视频会静音自动播放并循环。

普通用户更推荐使用应用内的「素材库」窗口（右键俏咪 → 素材库…），素材会存入 `~/Library/Application Support/Qiaomi/photos/`，拖入即生效，无需重新构建。

素材来源规则：用户素材库有内容时，俏咪只展示该目录中的素材；目录为空时才回退到 app 内置动作素材。图片和视频不会再叠加贴纸边框。透明 PNG 会按透明角色直接绘制；如果导入的是白底抠图 JPG，程序会在加载时将连通的白色背景转为透明后再绘制。
