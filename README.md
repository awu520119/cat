# 俏咪桌宠 v0.1.1

一只在 macOS 桌面陪伴你的本地小猫。支持动作动画、摸摸、拖拽、睡觉、气泡台词、励志语录，以及自己的图片和视频素材。

当前代码、资源与文档共同构成 v0.1.1 版本。应用版本以 `Info.plist` 为准。

## 构建与运行

```bash
./scripts/build.sh
open Qiaomi.app
```

构建脚本会按当前 Mac 的架构生成应用（Apple Silicon 为 arm64，Intel 为 x86_64）。也可用 Xcode 打开 `Qiaomi.xcodeproj`，工程只构建当前设备架构。需要分发时，可手动运行 `./scripts/make-dmg.sh`。

## 日常操作

- 单击猫咪：摸摸；双击：睡觉或叫醒；拖拽：移动位置。
- 右键：更多动作、语录、隐藏、鼠标穿透、素材库、设置和大小调整。
- 菜单栏爪印：显示或隐藏、睡觉、鼠标穿透、素材库、设置、退出。隐藏或开启鼠标穿透后，可从这里恢复。
- 触控板捏合：调整大小。窗口位置、大小、睡觉状态和当前素材会在重启后恢复。
- 互动累计亲密度等级；当前等级显示在右键菜单和设置中。

## 自己的素材

从右键菜单、菜单栏或设置中打开「素材库」，把图片或视频拖入即可。支持 jpg、jpeg、png、webp、heic、tiff、mp4、m4v、mov；视频静音循环播放。

素材存于 `~/Library/Application Support/Qiaomi/photos/`。有个人素材时，仅展示个人素材；素材库为空时，使用内置动作素材。图片和视频直接展示，不叠加装饰边框。透明 PNG 按角色绘制；白底抠图 JPG 会在载入时去除连通白色背景。也可把素材放进工程的 `photos/` 目录，重新构建后打包进应用。

## 设置

可修改名字、开关轻音效、选择打扰频率、控制空闲时的励志语录、编辑语录，以及设置开机自启。所有设置都保存在本机。

项目使用 Objective-C 和 AppKit，无服务端。主要代码位于 `Sources/Qiaomi/`，多语言文案位于 `Resources/`，内置动作素材位于 `assets/actions/`。
